# FDE Job Digest

A daily email digest of **Forward Deployed Engineer** roles scraped from
LinkedIn, Greenhouse, Lever, Ashby, Indeed, Wellfound, and Adzuna.
Each role gets a personalised "why I'd fit" one-liner powered by Claude.
Emails are sent with high-priority headers via Gmail SMTP.

## Quick start

### 1 — Clone / enter the directory

```bash
cd job-digest
```

### 2 — Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### 4 — Set up credentials

```bash
cp .env.example .env
```

Edit `.env` and fill in:

| Variable | Required | Where to get it |
|---|---|---|
| `GMAIL_ADDRESS` | ✅ | Your Gmail address |
| `GMAIL_APP_PASSWORD` | ✅ | [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) — needs 2FA enabled |
| `ANTHROPIC_API_KEY` | Recommended | [console.anthropic.com](https://console.anthropic.com/) |
| `ADZUNA_APP_ID` + `ADZUNA_API_KEY` | Optional | [developer.adzuna.com](https://developer.adzuna.com/) — free tier: 250 req/month |
| `CRUNCHBASE_API_KEY` | Optional | [data.crunchbase.com](https://data.crunchbase.com/docs) — free basic API |

> **Gmail App Password** — go to Google Account → Security → 2-Step Verification → App Passwords.
> Select "Other" and give it a name like "Job Digest". Copy the 16-character password into `.env`.

### 5 — Test dry run (no email sent)

```bash
python main.py --dry-run
```

Or save the rendered HTML to inspect it visually:

```bash
python main.py --dry-run --save-html preview.html
open preview.html
```

### 6 — Send a real email

```bash
python main.py
```

### 7 — Set up the daily cron job (7 AM)

```bash
bash setup_cron.sh
```

Logs are written to `digest.log` in the project directory.

To verify the cron entry: `crontab -l`
To edit or remove it: `crontab -e`

## Customisation

### Change search queries

Edit `SEARCH_QUERY` and `SEARCH_QUERY_VARIANTS` in `config.py`.

### Add more companies to Greenhouse/Lever/Ashby

Edit `GREENHOUSE_COMPANIES`, `LEVER_COMPANIES`, or `ASHBY_COMPANIES`
in `config.py`. The slugs are the subdomain/path component of each
company's job board URL:
- Greenhouse: `https://boards.greenhouse.io/{slug}`
- Lever: `https://jobs.lever.co/{slug}`
- Ashby: `https://jobs.ashbyhq.com/{slug}`

### Change the recipient or subject

Edit `TO_EMAIL` and `EMAIL_SUBJECT` in `config.py`.

### Change the cron time

```bash
crontab -e
```

Change `0 7 * * *` to any cron expression.
Use [crontab.guru](https://crontab.guru/) to build expressions.

## How "why I'd fit" works

1. **Claude API (preferred)** — If `ANTHROPIC_API_KEY` is set, each job gets a
   25-word first-person one-liner generated by `claude-haiku-4-5-20251001`
   based on Suraj's resume and the job description.
2. **Rule-based fallback** — If no key is set, keywords in the job title/description
   are matched to a set of curated snippets (defined in `ai_fitter.py`).

## Troubleshooting

| Problem | Solution |
|---|---|
| `Gmail auth failed` | Use an App Password, not your regular password. 2FA must be enabled. |
| `No jobs found` | LinkedIn/Indeed may have blocked the scraper IP. Try a VPN or run less frequently. |
| `anthropic not found` | `pip install anthropic` |
| `ModuleNotFoundError` | Make sure your venv is activated: `source .venv/bin/activate` |
| Crunchbase returning empty | The free API requires a key; scrape fallback is best-effort. |
